# Shorin's Linux Guide knowledge base (kb-shorinwiki)

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This repository packages [shorinwiki](https://github.com/SHORiN-KiWATA/Shorin-ArchLinux-Guide) as a knowledge base package for [Miyu](https://github.com/miyu-agent/miyu). After installation you get one more read-only knowledge base, `Shorin 的 Linux 指南` (Shorin's Linux Guide), and when the AI answers Linux questions it automatically recalls the relevant passages from it.

Install it by running:

```sh
miyu pkg install kb-shorinwiki
```

The repository contains the following:

- `package/`: the package itself. `package/kb/shorinwiki/` holds the wiki's Markdown documents, without the outdated tutorials in `wiki/legacy/` and without images: during sync, relative image links are rewritten to the raw file addresses of the upstream repository at the commit recorded in `UPSTREAM_COMMIT`. `kb.toml` holds the knowledge base's name and description; auto recall is on by default, and you can turn it off under `Knowledge` on the settings page.
- `tools/sync.sh <wiki checkout>`: updates the documents from the wiki and records the source commit (`UPSTREAM_COMMIT`) and the Git object hashes (blob hashes) of the referenced images (`UPSTREAM_IMAGES`). The comparison ignores the commit ids pinned in the links; if upstream only has new commits that touch neither the documents nor these images, this counts as no change and none of the three is modified. If the checkout is not a Git repository, or `wiki/` contains no Markdown at all, the script exits with an error and leaves the knowledge base, `UPSTREAM_COMMIT` and `UPSTREAM_IMAGES` unmodified. `.md` files that are symbolic links are not copied (the script prints a note on standard error, stderr, and this does not count as a failure). `tools/bump.sh`: sets the version to `0.<date>.<run of the day>`.
- `.github/workflows/update.yml`: checks the wiki once a day and releases a new version when there are new document changes; you can also run it by hand in GitHub Actions.
